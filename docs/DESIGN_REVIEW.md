# 筆記介面驗收

日期：2026-10-24。

新版以跨頁筆記、章節索引、手寫標題與可抽取的紙卡組成主流程。正文和原生控制保持清楚可讀，裝飾性側欄與靜態英雄插畫已由可操作的敘事試映取代。

## 參考與轉譯

- [MotionIn Console](https://motionin.design/gallery/console)：實際按鍵輸入與底邊收短的回饋，轉成印章式主操作。
- [MotionIn Hardback](https://motionin.design/gallery/hardback)：實際開書、收回及切換書本，轉成同一紙卡的離場與入場，以及頁緣和裝訂的材質關係。
- [Skillry 作品庫](https://skillry.dev/ai-videos/opus-5-5)：實際切換原作／重製比較及播放作品，轉成先預覽、再讀完整內容的操作順序。
- [Skillry 紙面到藍圖作品](https://skillry.dev/ai-videos/opus-5-5/heyiamnick-119558)：實際看見鉛筆排線、形狀與藍圖階段，轉成與敘事步驟連動的 SVG 筆畫。

上述案例僅提供互動原理與視覺研究；筆畫、介面與程式重新製作，未取用付費規格或外站素材。

## 已核對

- 1440px 桌機：兩行主標題、完整跨頁、三段草圖橫排，主操作位於第一頁。
- 390px 手機：連續單頁、索引標籤可橫向翻找、三段草圖保持橫排，紙卡完整可讀。
- 320–1440px 的六個主要畫面無水平溢位；手機輸入為 16px。
- 印章與次按鈕具有短行程按壓，鎖定、收藏、當前段落使用明確狀態。
- 連續抽選均產生新的入場動畫；改頁與條件變更會取消舊抽選。
- 故事試映可點選、播放、暫停，狀態文字同步提供給輔助技術。
- 減少動態時，紙卡、筆畫與按鈕位移均關閉。
