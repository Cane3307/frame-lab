# 簡單塗鴉介面檢查

日期：2026-10-24。

## 視覺方向

以使用者指定的簡單可愛、粗圓角、塗鴉與新粗獷主義重做。暖白背景搭配黃、粉、藍、綠四種實色；粗黑線和硬陰影貫穿按鈕、卡背、卡牆及詳情。不使用漸層。

## 已檢視

- 桌機：單一翻卡主動作與兩個主入口清楚，卡背使用原創小花和笑臉。
- 手機：標題、按鈕、卡片依序排列，抽到卡片直接列出故事步驟。
- 卡片列表：主題、編號、題材與架構可掃讀，整張卡可點入。
- 詳情：延續實色大卡，完整架構、複製按鈕、原生範例展開與拍攝提醒分段呈現。
- 按鈕：具備按壓位移、硬陰影變化與鍵盤焦點。封面的翻開提示也是實際按鈕。
- 減少動態：停用翻卡與按壓位移，保留立即結果和文字回饋。
