# 靈感場 FRAME LAB：設計與 UI／UX 驗收

日期：2026-10-24（Asia/Taipei）
審查角色：Agent OS 美術與 UI／UX 審查員
結論：獨立靜態複查通過；主代理 Chromium 自動驗收 9 組通過。沒有尚未處理的阻擋項目。

## 產品與視覺方向

創作者在白天的工作桌前，用筆電從既有素材找出影片方向，再整理成能開拍的企劃。介面採暖米白紙面、墨綠主動作與導航、橘色抽選訊號。拍板、取景框與編號提供辨識，表單與導航保留熟悉操作。

最終流程為：三軸篩選或抽選 → 查看組合與虛構教學示例 → 明確套入獨立企劃工作紙 → 編輯、保存與匯出。抽選本身不覆寫工作紙。

- 桌機：固定左導覽；資料庫集中瀏覽，工作紙畫面採編輯表單與敘事預覽雙欄。
- 1000px 以下：工作紙預覽移到表單之後。
- 760px 以下：導航改頂部可橫向捲動列；篩選採雙欄，工作紙單欄。
- 390px 以下：靈感卡片單欄，避免窄欄長文字。

## 主代理瀏覽器實測

依 TEST_RESULTS.json 與 smoke.cjs 交叉檢視，下列 9 組均通過：

1. Repository 子路徑載入全部相對資產，初始展示涵蓋七種主題。
2. 三軸篩選與鎖定抽選保留指定製作條件。
3. 詳情雙範例、收藏、工作紙、模式切換、確認框焦點與重新整理後草稿保存。
4. Markdown 下載及 JSON 備份還原保留繁體中文；錯誤匯入不覆寫資料。
5. skip link 保留畫面、使用者文字安全呈現、移除收藏後保留合理鍵盤焦點。
6. 12 公式、31 混搭與 12 則有來源知識正常呈現及篩選。
7. 1440、1024、768、390、320px 下，資料庫、工作紙、收藏、公式、知識與詳情六畫面皆無頁面水平溢位；手機輸入為 16px；reduced-motion 下 reveal animation 為 none。
8. 直接 file:// 開啟，不依賴伺服器或建置即可使用。
9. 210 個唯一組合、506 則示例，沒有瀏覽器錯誤或遺失本機資產。

自動測試涵蓋實際下載與還原，不只是檢查按鈕存在。

## 對比複查

方法：OKLCH 經 Oklab 轉換為線性 sRGB，依相對亮度計算；超出 gamut 的色值先裁切至 0–1。

| 文字／背景或邊界／背景 | 最終對比 | 結果 |
|---|---:|---|
| muted／paper | 5.94:1 | 一般文字通過 |
| muted／surface | 6.29:1 | 一般文字通過 |
| muted／soft | 5.43:1 | 一般文字通過 |
| ink／paper | 14.53:1 | 一般文字通過 |
| surface／green | 10.69:1 | 一般文字通過 |
| orange／orange-soft | 4.77:1 | 一般小字通過 |
| control-line／surface | 3.54:1 | 控制邊界通過 |

表單控制使用獨立 control-line，裝飾性分隔線維持較輕，兼顧辨識與畫面秩序。
