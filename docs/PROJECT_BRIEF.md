# 靈感場｜產品大綱

一個公開、免登入的短影音靈感卡工具。

## 主要畫面

1. **翻卡**：首頁只有張數選項、翻卡按鈕和卡片。選擇 1、3 或 5 張，卡片原位翻轉並展示架構。
2. **全部卡片**：一頁展開 210 張卡片，透過關鍵字或七種主題找方向。
3. **卡片詳情**：閱讀完整架構、兩個虛構示例與拍攝提醒，可複製架構。

## 操作原則

抽卡控制列固定在結果上方，頁面向下捲動時保持可用。卡片高度固定，連續抽卡不自動捲動畫面。同批卡片不重複，下一批排除上一批的卡片。進出詳情保留抽卡結果與閱讀位置。

## 設計

簡單可愛的塗鴉風格，使用粗黑線、大圓角、實色和硬陰影。不使用漸層。

## 內容

使用 210 種短影音架構與每張卡的兩個示例。範例協助理解架構，不代表真實個人經驗或保證創作成效。
