# 靈感場｜產品大綱

一個公開、免登入的短影音靈感卡工具。

## 主要畫面

1. **隨機翻一張**：翻開 210 種架構中的一張，直接列出題材、概念與故事步驟；按一下再翻。
2. **全部卡片**：一頁展開全部卡片，透過關鍵字或七種主題找方向。
3. **卡片詳情**：閱讀完整架構、兩個虛構示例與拍攝提醒，可複製架構。

## 設計

簡單可愛的塗鴉風格，使用粗黑線、大圓角、實色和硬陰影。不使用漸層。桌機與手機延續同一套卡牌語彙。

## 內容

使用 210 種短影音組合與每張卡的兩個示例。範例協助理解架構，不代表真實個人經驗或保證創作成效。

## 完成條件

訪客能翻卡、瀏覽全部卡片、搜尋、點進詳情與複製架構。返回列表保留條件及閱讀位置。所有畫面在手機可操作，具備鍵盤焦點及減少動態支援。
