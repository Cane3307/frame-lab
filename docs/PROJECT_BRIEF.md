# 靈感場 FRAME LAB｜專案大綱

## 目標

把 short-video-copy-lab 技能原型改造成可直接操作、編輯與部署的繁體中文靈感庫。交付純靜態成品與 GitHub Pages 設定方式。

## 工作範圍

1. 210 組三軸選題器、關鍵字搜尋、條件鎖定抽選。
2. 詳細紀錄與 506 則教學示例、12 公式、31 混搭。
3. 官方來源的短影音、長影音、長轉短知識庫。
4. 可填專案名稱與大綱的企劃工作紙、長短片敘事節奏。
5. 本機草稿／收藏／100份企劃、Markdown、AI 提示與 JSON 備份。
6. 響應式、焦點管理、減少動態、檔案開啟與 GitHub 子路徑驗收。

## 選定方向

評估科技控制台、小說書頁、創作工作桌三條路。科技視覺容易讓檢索和表單負擔過重，小說風格較適合長篇閱讀，工作桌最符合從選題到拍攝計畫的實際操作。選用米白工作紙、墨綠導覽、橘色場記、CSS 原創拍板。保留抽選揭示與節奏預覽的動態，避免自動播放。

## Agent OS 分工

- 主代理：意圖解碼、架構、前端實作、整合、瀏覽器驗收與文件。
- 資料代理：原型 JSON 分析、資料轉換、完整性驗證。
- 研究代理：短長片官方來源、知識筆記與來源界線。
- 設計代理：美術方向、UI／UX 獨立靜態審查、對比與焦點檢查。

本次 flags：NEEDS_PLAN=true、NEEDS_EVIDENCE=true、NEEDS_BUILD=true；NEEDS_SCHEDULE=false、NEEDS_LOOP=false、HIGH_STAKES=false。答錯成本中等，變更可逆。遇到前端問題依實測重現後修正，再回歸。

## 保存與限制

原技能與總報告未更動，研究／設計／驗收放 docs。無後端、帳號、同步、生成 API、影片下載或影片製作。長影音部分是明示的延伸企劃結構與官方來源筆記，不把原型 210 個短片組合重新宣稱為經驗證的長片公式。

## 成功條件

從開啟頁面、抽到靈感、填寫工作紙到匯出企劃，全程可操作；收藏與草稿重新整理後保留；可由 JSON 還原；320px 至 1440px 六個主要頁面不橫向溢位；以 repository 子路徑及 file:// 實測可載入。最終結果見 ACCEPTANCE.md 及 TEST_RESULTS.json。
