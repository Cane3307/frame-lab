# 彈窗與逐張翻牌驗收

日期：2026-10-24。

## 結果

tests/smoke.cjs 以 Chromium 執行 13 組驗收，全部通過；無 JavaScript 錯誤或相對資源載入失敗。結果見 [TEST_RESULTS.json](TEST_RESULTS.json)。

| 項目 | 實測 |
|---|---|
| 速度與閱讀 | 五張約 1.76 秒完成；彈窗捲動條為隱藏，實際滑鼠滾輪仍能閱讀下方內容 |
| 真正翻面 | 五張背面先展開；逐張檢查揭示張數；翻到中途時具有三維旋轉角度，結束後皆回到正面 |
| 1／3／5 張 | 數量、唯一性、保留卡片節點與固定按鈕正常；減少動態立即顯示 |
| 滑過與鍵盤 | 滑鼠放大、前景層級及左右鍵選牌正常 |
| 彈窗 | 點卡不改 URL、不切底頁；Tab 留在視窗內 |
| 完整還原 | X、Esc、遮罩關閉後，卡片編號、DOM 節點、選牌、每張矩形座標、scrollX／scrollY、焦點均還原 |
| 對應卡片連結 | 抽卡彈窗直接連到 #cards/同一編號並展開；關閉聚焦同一張列表卡，原篩選遮住目標時清除 |
| 列表 | 搜尋、篩選、捲動及選中項目在關閉後保留 |
| 內容底部 | 全部卡片的彈窗有「回到翻卡」與「沒靈感，再抽抽看」；翻卡彈窗可前往全部卡片 |
| 內容功能 | 兩個示例可展開，複製架構及手動選取方案正常 |
| 快速重開 | 舊的關閉事件不會誤關新彈窗；開啟中切換卡片深連結正常 |
| 相容深連結 | 舊卡片網址開啟列表上的彈窗，關閉回列表 |
| 響應式 | 320、360、390、768、1024、1440px 的手牌、列表與彈窗無水平溢位 |
| 全資料 | 320px 下逐一渲染 210 張牌面，沒有卡內捲動或文字裁切 |
| 中途取消 | 聚牌、背面展牌、逐張翻牌各階段換頁都能還原上一手，不會延遲改動 |
