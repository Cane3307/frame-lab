Frame WenKai

A locally hosted character subset of LXGW WenKai TC Regular, renamed for
this derivative. Original copyright and SIL Open Font License are retained
in OFL.txt.

Original family: LXGW WenKai TC
Project: https://github.com/lxgw/LxgwWenkaiTC
Distribution source:
https://github.com/google/fonts/tree/main/ofl/lxgwwenkaitc

Only headings and handwritten annotations use this face. Interface controls
use system fonts. The website does not request third-party font services.
