# 靈感場 FRAME LAB

把一點靈感，變成下一個好故事。

像翻一本創作筆記，從左頁選方向，在右頁抽出一張新靈感。靈感場陪創作者從零散念頭找到題材，再整理成可以開拍的故事。適合短影音選題、長影音規劃，以及還不知道下一支影片要拍什麼的時候。

![靈感場介面預覽](docs/screenshots/preview.png)

## 找到下一個切角

- **210 種靈感組合**：依內容主題、呈現形式與標題切角探索題材。
- **紙卡抽選**：鎖定想保留的方向，抽出下一張靈感。
- **故事試映**：點選或播放三個敘事段落，先看見這個題材可以怎麼說。
- **敘事工具箱**：12 種公式、31 種混搭與完整範例，幫助故事建立脈絡。
- **影音知識筆記**：整理短影音、長影音與長片轉短片的創作思路，附上參考來源。

## 把念頭整理成企劃

工作紙整合企劃名稱、目標觀眾、已有素材、開場、大綱與拍攝筆記，並提供長短影音的結構提示與敘事節奏預覽。

喜歡的組合可以收藏，完成的企劃可以保存、匯出 Markdown，或整理成 AI 協作提示。

## 你的創作，由你保存

免註冊，支援桌機與手機。收藏、草稿與企劃儲存在目前使用的瀏覽器，不會自動同步到其他裝置；可透過備份匯出與匯入轉移。

資料庫中的案例是虛構示例，適合用來理解結構與啟發創意。實際創作仍需以自己的素材、經歷與可查證資料為基礎。
