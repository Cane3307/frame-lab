# 靈感場 FRAME LAB

卡住了？翻一張就好。

一個簡單、可愛的短影音靈感工具。從 210 種故事架構裡隨機翻一張，找到下一支影片的起點。

![靈感場介面預覽](docs/screenshots/preview.png)

## 一張卡，一個新點子

- **隨機翻一張**：翻開靈感卡，直接看題材與故事步驟。不知道拍什麼時，先抽一個方向。
- **全部卡片**：一次瀏覽 210 張卡片，用主題或關鍵字找到喜歡的切角。
- **點進去看看**：每張卡都有完整架構、兩個示例與拍攝提醒，也能一鍵複製架構。

免註冊，支援桌機、手機與鍵盤操作。卡片與示例直接在瀏覽器中讀取。

案例皆為虛構示例，用來幫助理解故事結構。創作時，請換成自己的真實素材與經歷。
